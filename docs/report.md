## Відповіді на контрольні запитання

1. **Яка адреса сторінки в браузері? З яких частин вона складається?**
   Адреса сторінки: `http://127.0.0.1:5500/index.html`. Вона складається з:
   - `http://` — протокол передачі даних;
   - `127.0.0.1` — IP-адреса локального комп'ютера (localhost);
   - `:5500` — номер порту Live Server;
   - `/index.html` — шлях до файлу на сервері.

2. **Скільки запитів зробив браузер при завантаженні сторінки і чому саме стільки?**
   Браузер зробив 2 основні HTTP-запити (за HTML-документом `index.html` та за файлом зображення). Браузер спочатку завантажує код сторінки, знаходить тег `<img>` і робить окремий запит для завантаження картинки.

3. **Що відбулось, коли ти поставив неправильний шлях до зображення?**
   Сервер повернув помилку зі статусом `404 Not Found`. Запит у вкладці Network підсвітився червоним коліром, а на сторінці замість картинки з'явився текст з атрибута `alt`.

4. **Чому зміни, зроблені через DevTools, зникли після F5?**
   DevTools змінює DOM-дерево та стилі лише в оперативній пам'яті браузера на стороні клієнта. При оновленні сторінки (F5) браузер знову завантажує початковий файл `index.html` з диска, де ці зміни не зберігалися.

5. **Хто в цій схемі клієнт, а хто сервер?**
   Клієнт — це веб-браузер (Microsoft Edge), який надсилає запити та відображає сторінку. Сервер — це розширення Live Server у VS Code, яке приймає запити та надсилає файли проєкту.

   ## W-07. Сторінка «Про автора»

Семантична розмітка визначає структуру та змістове значення елементів веб-сторінки відповідно до їхнього функціонального призначення. На відміну від універсальних контейнерів `<div>`, семантичні теги покращують доступність (Accessibility) для зчитувачів екрана та оптимізують індексацію сайту пошуковими системами (SEO). Завдяки семантиці код стає більш структурованим, зрозумілим для читання та легшим у подальшій підтримці.

**Використані теги:** `<header>`, `<nav>`, `<main>`, `<article>`, `<section>`, `<figure>`, `<figcaption>`, `<footer>`, `<h1>`, `<h2>`, `<p>`, `<strong>`, `<em>`, `<ul>`, `<li>`, `<table>`, `<thead>`, `<tbody>`, `<tr>`, `<th>`, `<td>`, `<a>`, `<img>`.

## W-10. Flexbox, адаптивність і форма

Властивість `flex-wrap: wrap` дозволяє flex-елементам автоматично переноситися на новий рядок, якщо їм не вистачає місця в контейнері. 

Медіа-запити (`@media`) потрібні для зміни стилів сторінки залежно від характеристик пристрою (наприклад, ширини екрана). Вони забезпечують адаптивність верстки, перебудовуючи елементи у вертикальні колонки на мобільних телефонах (шириною до 600px).

Атрибут `name` необхідний для ідентифікації полів при передачі даних на сервер (наприклад, у Flask), а атрибут `id` є унікальним ідентифікатором елемента в HTML-документі, який використовується для зв'язку з тегом `<label>` (через `for`) та маніпуляцій з DOM у JavaScript.
